* Approval invariant

Lifecycle and approval are different facts.

=#+status: REVIEW= does not mean =#+approval_state: APPROVED=.

Canonical approval states remain:

- PENDING
- APPROVED
- REJECTED

Partial canonical approval metadata is invalid.

* Issue research transaction invariant

Every issue-backed research request/pass must have a durable transaction node under:

#+begin_example
roam/research/ardr-issues/ARDR-ISSUE-<number>-<slug>.org
#+end_example

The transaction may link an existing canonical domain research node. Do not duplicate domain research merely because another issue references it.

* Implementation slots

Each project has zero or one active implementation design under =roam/implement/<project>/=. Independent projects may proceed concurrently.

Do not auto-activate implementation after research/design promotion.
